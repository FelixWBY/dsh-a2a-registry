# A2A MVP：PRD 与待办

## PRD

### 目标与流程

在独立的 `dsh-a2a-registry` 仓库交付注册站，外部 DeepSeek Harness 完成本地选择会话 → 预览并披露 → 注册站查看 → 导入隔离分支或向来源提问 → 查看文本回复的闭环，并提供可交付给公网 TLS 代理的 Registry 入口。复用现有实现，不新增通用框架。仅维护本文中文版本。

独立交付范围为注册站前后端、协议组件及部署模板，不包含 Harness 执行器。下文历史验收记录来自拆分前工作区，不等于独立仓库已完成公网验收；独立启动与验证方式以根目录 README 为准。

### 用户与权限

来源所有者选择披露范围、受众和到期时间，可暂停同步或撤回。获授权的同组织成员可以查看、导入和提问。注册站已实现标准 OIDC Authorization Code + PKCE，并用本地 Keycloak 完成真实登录、成员映射与退出验收；生产仍须选择并配置正式 IdP 租户。依赖认证的操作显示具体缺失配置，不使用假登录。合成身份与回环 Keycloak 均只用于明确标注的本地测试，不作为上线身份。

### 必需规则

- 每次读取、导入、派发和回复均检查当前权限及固定检查点；暂停同步不等于撤回权限。
- 仅共享获准文本；不共享附件、文件正文、原始工具结果、隐藏推理或秘密。预览不能承诺自动发现所有秘密。
- 导入／入站分支不继承来源工具、工作目录或环境权限；只允许文本处理，不允许远程命令、文件操作或权限升级。
- 请求、分支 ID 与结果须持久化；重复投递不重复创建或执行，重启后可恢复状态。
- 历史事件以其签名内的 `occurredAt` 选择当时有效的实例密钥；检查点不含签名时间，只接受接收时仍有效的连接密钥。
- 撤回／到期拒绝新的读取与请求；已导入副本和已返回回复不能召回。
- 加载、空列表、未配置、离线、失败、到期、撤回、失权均有明确页面状态；不展示虚构业务数据。
- 披露、分支、审计、成员与节点列表在窄屏中改为带字段名的记录，不依赖横向滚动；长标识可视觉截断，但完整值必须保留供复制与辅助技术读取。
- 公网部署必须使用正式域名、受信任证书和回环反向代理；不得公开测试身份、测试证书、本地共享密钥或未配置的生产能力。

### MVP 验收

通过正常 DSH／Registry 启动入口，在桌面和窄屏完成上述闭环；刷新或重启后能找到请求与回复；重发不重复执行；撤回后拒绝新访问；共享文本不能调用工具。只运行改动相关测试及这条主流程，不以覆盖率数字代替可用性。本地 Keycloak 登录通过不等于生产 IdP 已配置，正式租户与公网 HTTPS 未验收前不能宣布上线可用。

### 本轮不做

跨组织／公开／匿名共享、附件、多模态、全文检索、批量导出、P2P、严格端到端加密、远程动作，以及新增 Registry 业务数据后端、完整运维平台和全面压力测试。现有安全约束不因缩小范围而放宽。
